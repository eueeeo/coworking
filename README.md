# Коворкинг

Веб-приложение для учета и бронирования рабочих мест в коворкинге. Разработано на ASP.NET Core Razor Pages с использованием Entity Framework Core и реляционной базы данных MySQL 8.0.

## Основные возможности

### Клиентский функционал
- Каталог рабочих мест с фильтрацией по этажам, зонам, типам пространств и оборудованию
- Карточка рабочего места с техническими характеристиками, тарифом и перечнем оснащения
- Онлайн-бронирование на выбранную дату и интервал времени с проверкой доступности и защитой от пересечений
- Личный кабинет с разделением бронирований на активные и архивные, а также возможность отмены заявки

### Панель администратора
- Журнал всех бронирований коворкинга с фильтрацией по дате, статусу и номеру места
- Управление структурой коворкинга: справочники этажей, зон, типов мест, тарифов и оборудования
- Управление фондом рабочих мест и учетными записями пользователей
- Встроенная аналитическая отчетность: расчет выручки, загрузка фонда, средний чек

### Безопасность и архитектура
- Cookie-аутентификация с разделением ролей (Администратор и Клиент)
- Криптографическое хэширование паролей алгоритмом BCrypt
- Серверный контроль прав доступа к административным разделам
- Параметризованные LINQ-запросы Entity Framework Core
- Переключение светлой и темной тем оформления

## Стек технологий

- **Платформа:** .NET 9.0 (C#)
- **Фреймворк:** ASP.NET Core Razor Pages
- **База данных и ORM:** MySQL 8.0, Entity Framework Core 9 (Pomelo MySQL)
- **Безопасность:** BCrypt.Net-Next, Cookie Authentication
- **Фронтенд:** HTML5, CSS3, Bootstrap 5, JavaScript

## Структура проекта

- `src/Coworking/Pages/` — страницы Razor Pages (каталог, бронирование, личный кабинет, админ-панель)
- `src/Coworking/Models/` — доменные сущности (User, Workspace, Booking, Floor, Zone, Amenity и др.)
- `src/Coworking/Data/` — контекст базы данных `AppDbContext` и конфигурации сущностей EF Core
- `src/Coworking/Services/` — сервисы приложения (EmailSender)
- `src/Coworking/wwwroot/` — статические ресурсы (стили, скрипты, библиотеки)
- `db/` — SQL-скрипты структуры (`schema.sql`) и начального наполнения (`seed.sql`)

## База данных

Данные хранятся в реляционной базе данных MySQL 8.0, спроектированной в третьей нормальной форме (3НФ):

- `users` — учетные записи пользователей с ролями и хэшами паролей
- `floors`, `zones`, `workspace_types` — структура помещений и типы пространств
- `amenities`, `amenity_categories` — справочник оборудования и сервисов
- `workspaces`, `workspace_amenities` — фонд рабочих мест и привязка удобств
- `bookings` — заявки на бронирование с контролем временных интервалов и стоимости
- `email_confirmations` — токены подтверждения учетных записей

## Установка и запуск

Для работы требуются [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) и СУБД MySQL 8.0.

1. **Создать и наполнить базу данных MySQL:**
   ```bash
   mysql -u root -p < db/schema.sql
   mysql -u root -p < db/seed.sql
   ```

2. **Настроить подключение к базе данных:**  
   В `src/Coworking/appsettings.json` указать строку подключения к локальной СУБД:
   ```json
   "ConnectionStrings": {
     "DefaultConnection": "Server=localhost;Port=3306;Database=coworking;User ID=root;Password=your_password;CharSet=utf8mb4;"
   }
   ```

3. **Запустить проект:**
   ```bash
   dotnet run --project src/Coworking/Coworking.csproj
   ```
   Приложение откроется по адресу `http://localhost:5000`.
