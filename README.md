# Коворкинг

Веб-приложение для учета и бронирования рабочих мест в коворкинге, разработанное на ASP.NET Core Razor Pages с использованием Entity Framework Core и реляционной базы данных MySQL 8.0.

## Основные возможности

### Клиентский функционал
- каталог рабочих мест с многокритериальной фильтрацией (по этажу, зоне, типу пространства и требуемому оборудованию)
- подробная карточка рабочего места с техническими характеристиками, почасовым тарифом и перечнем оснащения
- онлайн-оформление бронирования на выбранную дату и временной интервал
- автоматический расчет стоимости аренды на основе почасового тарифа
- защита от некорректного ввода (проверка бронирования в прошлом, контроль начала и окончания аренды)
- личный кабинет с разделением бронирований на активные и архивные
- отмена предстоящих бронирований непосредственно из личного кабинета

### Администрирование и учет
- журнал всех бронирований коворкинга с фильтрацией по статусу, дате и номеру места
- оперативное изменение статуса заявки (подтверждено, завершено, отменено)
- справочник этажей коворкинга (добавление, редактирование, удаление с контролем целостности)
- справочник функциональных зон (привязка к этажам, описание назначения)
- справочник типов рабочих мест и почасовых тарифов
- классификатор оборудования и удобств с разделением по категориям (мебель, IT-оборудование, сервисы)
- управление фондом рабочих мест с привязкой к зонам, типам и наборам удобств
- управление учетными записями пользователей с возможностью блокировки доступа
- встроенная аналитическая отчетность: расчет выручки, загрузки фонда, средних чеков и распределения бронирований по типам пространств

### Безопасность и архитектура
- безопасная Cookie-аутентификация с разделением ролей (Администратор и Клиент)
- криптографическое хэширование паролей алгоритмом BCrypt
- серверный контроль прав доступа к административным маршрутам
- модуль подтверждения электронной почты (встроенная локальная песочница для тестирования)
- параметризованные LINQ-запросы Entity Framework Core, исключающие SQL-инъекции
- переключение светлой и темной тем оформления с сохранением состояния в браузере

## Структура проекта

- `src/Coworking/Pages/` — страницы Razor Pages (каталог, личный кабинет, авторизация, административные разделы)
  - `Pages/Index.cshtml` — главная страница и каталог рабочих мест с фильтрами
  - `Pages/Bookings/` — оформление бронирования и личный кабинет клиента
  - `Pages/Admin/` — административные панели управления (бронирования, пользователи, этажи, зоны, тарифы, удобства, отчеты)
  - `Pages/Account/` — аутентификация, регистрация, подтверждение email
- `src/Coworking/Models/` — доменные сущности (User, Workspace, Booking, Floor, Zone, WorkspaceType, Amenity и др.)
- `src/Coworking/Data/` — контекст базы данных `AppDbContext` и конфигурации сущностей EF Core
- `src/Coworking/Services/` — сервис почтовых уведомлений (`EmailSender`)
- `src/Coworking/wwwroot/` — статические ресурсы (стили CSS, скрипты JavaScript)
- `db/` — SQL-скрипты развертывания структуры базы данных и наполнения демонстрационными данными
  - `db/schema.sql` — DDL-скрипт создания таблиц, связей и внешних ключей
  - `db/seed.sql` — начальные демонстрационные данные
- `docs/` — проектная документация, интеграционные тесты и журнал разработки

## База данных

Вся информация хранится в реляционной базе данных MySQL 8.0 (`coworking`), спроектированной в третьей нормальной форме (3НФ):

- `users` — учетные записи пользователей (ФИО, email, хэш пароля BCrypt, роль, статус блокировки, статус подтверждения email)
- `floors` — этажи коворкинга (номер, название)
- `zones` — функциональные зоны (название, этаж, описание)
- `workspace_types` — типы рабочих пространств (название, почасовой тариф, описание)
- `amenity_categories` — категории оборудования и сервисов
- `amenities` — справочник доступных удобств и оборудования
- `workspaces` — рабочие места фонда коворкинга
- `workspace_amenities` — таблица связи «многие-ко-многим» между рабочими местами и удобствами
- `bookings` — заявки на бронирование (пользователь, рабочее место, дата/время начала и окончания, сумма, статус)
- `email_confirmations` — токены подтверждения учетных записей

## Установка и запуск

Для работы требуются [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) и СУБД MySQL 8.0.

1. **Создать и наполнить базу данных MySQL:**
   ```bash
   mysql -u root -p < db/schema.sql
   mysql -u root -p < db/seed.sql
   ```

2. **Настроить подключение к базе данных:**  
   В `src/Coworking/appsettings.json` указать строку подключения к локальной СУБД:
   ```json
   "ConnectionStrings": {
     "DefaultConnection": "Server=localhost;Port=3306;Database=coworking;User ID=root;Password=your_password;CharSet=utf8mb4;"
   }
   ```

3. **Запустить проект:**
   ```bash
   dotnet run --project src/Coworking/Coworking.csproj
   ```
   Приложение откроется по адресу `http://localhost:5000`.
