# Инструкции для курсового проекта Coworking

## Назначение
Разработка учебного веб-приложения для учета и бронирования рабочих мест в коворкинге.

## Технологии
- MySQL 8
- C#
- ASP.NET Core Razor Pages
- Entity Framework Core (Pomelo.EntityFrameworkCore.MySql)
- HTML, CSS и обычный JavaScript
- Cookie-аутентификация
- Роли: Администратор и Клиент
- BCrypt для хэширования паролей

Не меняй технологии без согласования.

## Обязательные правила
1. Перед началом работы изучай доступные материалы в docs/source.
2. Строго соблюдай лист задания и методические указания.
3. Не добавляй лишние функции, библиотеки и сложную архитектуру.
4. Не создавай файлы с дублирующимся содержимым.
5. Не перезаписывай исходные документы.
6. Используй параметризованные SQL-запросы / LINQ-запросы EF Core.
7. Проверяй ввод на сервере и корректно обрабатывай ошибки.
8. Проверяй права доступа пользователей на сервере.
9. Не храни пароли в открытом виде и секреты в Git.
10. Не утверждай, что проверка прошла, если она фактически не выполнялась.
11. Комментарии в коде пиши на русском языке, кратко.
12. Интерфейс должен быть простым и аккуратным, без перегруженного дизайна.

## Порядок работы
Работай по одному этапу за раз.

Перед каждым этапом:
- изучи требования;
- составь план;
- перечисли создаваемые и изменяемые файлы;
- опиши критерии готовности;
- дождись моего подтверждения.

После выполнения:
- проверь изменения;
- запусти сборку или тесты, если это возможно;
- укажи фактически проверенные результаты;
- перечисли изменённые файлы;
- обнови docs/PROGRESS.md.

Не переходи к следующему этапу без подтверждения.

## Работа с документацией
Пояснительную записку готовь на русском языке, в безличном научном стиле. Строго соблюдай структуру и оформление из методических указаний. Не выдумывай сведения, источники и результаты тестирования.

Если материалов недостаточно или требования противоречат друг другу, сообщи об этом и запроси решение. Не делай предположений молча.
